# 快速上手

给第一次参与共创的同事看的 **三分钟指南**。

## 1. 找到要改的页面

在首页列表里点标题，或直接用站内搜索（M2 接 Pagefind）。

## 2. 直接改

- 工具栏支持标题、粗体、斜体、列表、表格、代码块、引用、链接、图片
- 图片会自动压成 WebP，单张不超过 800KB
- 粘贴内容时不要带整页 HTML，编辑器只保留可用格式

## 3. 保存与冲突

保存成功后阅读页最多 15 秒可见新版。若提示冲突，说明别人先保存了，刷新后再改。

> 版本历史：每次保存都会留一条记录，M2 支持一键还原。

```bash
npm run dev      # 本地启动
npm run build    # 构建检查
npm run test:store
```
