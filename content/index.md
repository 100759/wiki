# 欢迎来到共创 Wiki

这是一个 **多人共创** 的示例页面，用来验证 M1 的读写链路。

## 本站怎么用

1. 打开任意页面，点右上角「编辑」。
2. 直接在富文本里改，不用写 Markdown，也不用 GitHub 账号。
3. 点「保存」，刷新阅读页即可看到新版。

> 内容存 GitHub，读者免登录；共创者只需要密码。

### 格式清单

- 粗体、*斜体*、~~删除线~~
- 站内指南：[快速上手](/w/guide.start)
- 表格、代码块、引用、图片

| 角色 | 能做什么 | 说明 |
| --- | --- | --- |
| 读者 viewer | 阅读 | 免登录 |
| 编辑者 editor | 编辑保存 | 邀请码加入 |
| 管理员 admin | 编辑 + 用户管理 | 站点维护 |
